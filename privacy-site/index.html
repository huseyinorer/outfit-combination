Outfit Combination Privacy Policy

Last updated: November 7, 2026

This policy explains how the Outfit Combination Android application processes data.

1. Data controller and contact

The application is developed by Hüseyin Örer. You can use the support and privacy request page for privacy-related requests. The developer identity and contact method must match the app store listing before publication.

2. Data stored on your device

Clothing photos, clothing attributes, drafts, favorite outfits, learned corrections, and app settings are stored in the app's private local storage. No user account is created. This data remains on the device until you delete it, clear the app data, or uninstall the app.

3. Data processed when AI is enabled

After you provide explicit consent, a reduced-size clothing photo is sent to the backend hosted on Render and to the OpenAI API for clothing analysis. Outfit requests contain only your preferences, random clothing identifiers, and textual clothing attributes. They do not contain photos, local file paths, image URLs, or base64 image data.

4. Purposes and legal basis

Data is processed only to identify clothing attributes, generate outfit suggestions, prevent abuse, control service costs, and maintain service security. AI processing is based on your explicit consent. Demo mode, manual clothing entry, and the local outfit engine remain available without consent.

5. Retention

The backend does not permanently store your wardrobe or clothing photos in its database. OpenAI requests use store=false. According to OpenAI's official API data controls, API content is not used to train models by default, while abuse-monitoring logs may be retained for up to 30 days. A pseudonymous installation identifier and daily or monthly AI usage counters are retained for cost and abuse control and are deleted when they are older than 13 months.

6. Service providers and international transfers

Render provides backend hosting, Neon provides the usage-quota database, and OpenAI provides image and text analysis. Their infrastructure may process data outside Türkiye. The OpenAI API key is stored only in the backend environment and is never embedded in the mobile app.

7. Deletion and your rights

You can delete clothing records, photos, favorites, drafts, learned corrections, and settings from this device by selecting Tüm yerel verilerimi sil in Settings. AI consent can be withdrawn from the same screen. Requests for access, correction, deletion, or other privacy rights can be submitted through the contact channel above.

8. Security

Production API connections use HTTPS. The AI provider key is not included in the mobile application. AI endpoints are protected with a server-signed installation token, request rate limits, and persistent daily and monthly usage quotas.
